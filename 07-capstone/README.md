# 阶段七：综合项目交付（6 课）

## 课程清单

1. 综合项目需求：先写行为合同与架构决策
2. 前端聊天界面：状态清楚，来源可查
3. 知识库交付：可重建、可追溯、可撤下
4. Agent、MCP 与 Memory 集成：保留独立权限
5. 系统测试、性能与部署：把未测项留在报告中
6. 最终验收与复盘：交付证据链

## 配套代码

综合运用 `ai-lab/` 中的全部模块，重点关注：
- `ai-lab/src/server.ts` + `ai-lab/public/index.html` — 前端聊天界面
- `ai-lab/src/mcp-agent.ts` — Agent + MCP + Memory 集成
- `ai-lab/tests/core.test.ts` — 测试用例参考
- `ai-lab/Dockerfile` — 容器化部署示例
