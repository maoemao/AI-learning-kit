# 阶段三：高级 RAG 与质量评估（8 课）

## 课程清单

1. 混合检索与 RRF：融合排名，不混淆分数
2. 重排与上下文：把有限窗口用在必要证据上
3. 查询改写、Multi-Query 与 HyDE
4. Parent-Child 与多跳：先证明真的需要两段
5. 引用、忠实度与拒答：三把尺子
6. 多轮与冲突：澄清比猜版本更可靠
7. 评测集与指标：冻结标准，再测系统
8. 对照实验：只改变一个条件，公开全部结果

## 配套代码

- `ai-lab/src/advanced.ts` — 词典改写、标识符启发式重排、父扩展、受限并发
- `ai-lab/src/retrieval.ts` — RRF 融合算法、ID 证据组指标
- `ai-lab/evals/dev.json` — 公开教学评测集

## 学习目标

- [ ] 理解 RRF 如何融合 BM25 和向量检索的排名
- [ ] 知道 reranker 和 HyDE 的原理（代码中是教学基线，非学习型）
- [ ] 能设计评测集并运行 `npm run eval`
- [ ] 理解为什么"只改变一个条件"对实验很重要
